# Rust vs Zig: size and cost

Generated by `cargo run --release` in this repository. Costs are metered by soroban-env-host 29 with mainnet's cost models and fee settings (`harness/config/mainnet-settings.xdr`). Fees are resource fees in stroops (1 XLM = 10,000,000 stroops), excluding the inclusion fee bid.

- **Rust**: stellar/soroban-examples, soroban-sdk 28, built with `stellar contract build`.
- **Zig small**: zig-soroban-sdk, `ReleaseSmall` (no overflow checks).
- **Zig safe**: zig-soroban-sdk, `ReleaseSafe` (traps on overflow, like Rust's `overflow-checks = true`).

## Equivalence check

Each Zig build must return the same values, emit the same events and leave the same storage as the Rust build, or its costs are not comparable.
